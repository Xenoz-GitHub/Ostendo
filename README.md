## >> What is Ostendo?

**Ostendo** (Latin for "show" or "display") is a free portfolio platform that helps students create professional portfolio websites without any coding knowledge. Choose from multiple templates, customize your design, and get your own personal URL in minutes.

```
┌─────────────────────────────────────────────────────────────┐
│  Before Ostendo          →          After Ostendo           │
├─────────────────────────────────────────────────────────────┤
│  No portfolio            →    Your own website               │
│  Hidden on resume        →    ostendo-ashen.vercel.app/yourname   │
│  Hard to share work      →    One link to everything         │
│  Hours of coding         →    5 minutes to publish           │
└─────────────────────────────────────────────────────────────┘
```

## >> Getting Started

### 1. Create Your Account

Visit **[ostendo-ashen.vercel.app/signup](https://ostendo-ashen.vercel.app/signup)**

```
Enter your:
  //  Full name
  //  Email address
  //  Password
```

### 2. Verify Your Email

Check your inbox and click the verification link.

### 3. Complete Onboarding

```
>>>  Choose your unique username
>>>  Add your headline (e.g., "Computer Science Student")
>>>  Write a short bio
```

### 4. Add Your Content

From your dashboard, add:

```
[ Projects ]     Your best work with descriptions and links
[ Education ]    Schools, degrees, and graduation dates
[ Experience ]   Internships, jobs, and leadership roles
[ Skills ]       Programming languages, tools, and expertise
```

### 5. Choose Your Look

```
Template Options:
  ( ) Minimal     - Clean and professional
  ( ) Developer   - Code-focused layout
  ( ) Creative    - Bold and visual
  ( ) Editorial   - Story-driven design

Customize:
  >>  Pick your brand colors
  >>  Choose typography
  >>  Adjust spacing and layout
```

### 6. Publish

Click **"Publish Portfolio"** and your site goes live at:

```
https://ostendo-ashen.vercel.app/[your-username]
```
